# Admin UI (Operator Console)

Minimal React SPA (TanStack Router + Query, Tailwind, shadcn) shipped as
static assets by `apps/admin`. Cloudflare Access guards the perimeter.

## Auth model

- The admin worker sits behind Cloudflare Access. The browser never sees
  the SPA shell unless CF Access has issued and validated a
  `cf-access-jwt-assertion` cookie (D19/D38). The SPA does **not** run a
  Better Auth client and does **not** call `/api/auth/*`.
- On mount, `OperatorProvider` calls `GET /api/admin/me` for the operator
  identity (id, email, role, status). 401/403 renders the
  "Session expired — refresh to re-authenticate" page. The endpoint is not
  yet implemented in `apps/admin/src/server.ts` (`TODO(api-gen)`).
- Action visibility is gated by `useOperator().can(action)` against
  `OPERATOR_PERMISSIONS` from `@repo/authorization`. These are presentation
  hints only — the server's `requireOperator()` is the source of truth.

## Routes

- `/` Dashboard

- `/audit-logs`
- `/global-admins`
- `/system` (placeholder, `TODO(operator-console-v2)`)

## Bindings + dependencies

- Served same-origin by `apps/admin` via the `ADMIN_UI` assets binding.
  All API calls use relative URLs (`/api/admin/...`).
- TanStack Router file-based routes under `src/routes`. The route tree is
  generated by Vite at build time; `bun run gen-routes` runs the same
  generator out-of-band when you cannot run Vite.
- API client is a typed `fetch` helper in `src/lib/api.ts`. The admin
  worker has no `openapi.cache.json` yet, so `@hey-api/openapi-ts`
  generation is wired up in a follow-up. Endpoints with no spec carry a
  `TODO(api-gen)` comment.

## Testing

- Page components live in `src/modules/*/<page>.tsx` and accept props for
  search/params so they can be rendered without booting the router. The
  thin wrappers in `src/routes/*` resolve those props and forward to the
  page component.
- `src/__tests__/pages.smoke.test.tsx` mounts every page with a mocked
  operator (`__tests__/operator-mock.tsx`) and a stubbed global `fetch`.
