# Web Modules

Feature modules for the React frontend.

## Core Modules
- `auth`, `permissions`, `layout`, `ui`, `common`, `errors`

## Feature Modules
- `dashboard`, `users`, `audit-logs`, `settings`, `data-table`

## Shared Rules
- Keep module code colocated by feature (`components`, `hooks`, `table`, `index.ts`).
- Keep generated API types/client usage inside query and mutation layers.
